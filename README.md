# Own Two Feet

Website for **Own Two Feet**, live, in-person life-skills workshops for boys and young men in grades 3–8, run with schools and community groups.

**Live site:** https://apollorracing.github.io/owntwofeet/

Built by Dane, Jewell and Marco (ENT 3315 venture project, Baylor University).

## What's here

| File | What it is |
|---|---|
| `index.html` | The whole site in one file: HTML, CSS and JavaScript |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |
| `CLAUDE.md` | Project notes and rules for Claude Code when editing this repo |
| `README.md` | This file |

## Pages on the site

- **Home**: hero with 3D tools, why it matters, topics explorer, session walkthrough, interview quotes, info for schools, activity previews, FAQ, interest form
- **Workshops**: planned formats, age groups, who does what
- **Activities**: Tool Time (3 rounds), Saturday on $25, Scam or Safe?, plus coming-soon previews
- **Our Story**: why we started, what we heard in interviews, what we believe
- **Get Involved**: ways to help and the interest form

There's also a "Questions?" help chat with saved answers. It isn't a live chat.

## Run it locally

No build step. Open `index.html` in Chrome, Safari or Edge.

Phone previews (Files, Drive, Gmail) often block scripts. The site still shows everything in that case, but the menu, activities and 3D won't run. Open it in a real browser to test.

## Update the live site

1. Edit `index.html`
2. Commit and push to `main`
3. GitHub Pages updates in about a minute
